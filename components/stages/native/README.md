# The level helper

A small UE4SS 3.0.1 C++ mod that loads and unloads the stages' levels for the Lua scripts. UE4SS 3.0.1's Lua cannot
call `LevelStreamingDynamic.LoadLevelInstance` on this game (its `bool` out-parameter breaks the argument stack), so
this helper makes the call. [HOW-IT-WORKS.md](../docs/HOW-IT-WORKS.md) describes the file protocol.

- `src/helper_glue.cpp`: this mod's part: reading requests, loading and unloading, the heartbeat.
- `src/main.cpp`: generated by `tools/make_helper_source.py` from `helper_glue.cpp` and four sections of our Junon
  Colosseum helper (the game-thread check, the code-byte checks, the loader-idle check and the safe-point gate),
  copied unchanged because they took a lot of live testing to make safe. `src/find_addresses.hpp` is copied whole.
  Regenerate it when those sections change: `python tools/make_helper_source.py <Junon Colosseum checkout>`.

## Build

Needs Visual Studio 2022 (C++), CMake, and the RE-UE4SS 3.0.1 sources with an import library from a 3.0.1 build.

1. Copy `build-config.example.json` to `build-config.local.json` and set your paths.
2. `tools/Build-Native.ps1 -BuildDirectory <folder> -ConfigPath native/build-config.local.json`
3. The script prints the SHA-256 of `<folder>/Release/main.dll`. Install it as
   `End/Binaries/Win64/ue4ss/Mods/SimulatorStages/dlls/main.dll`.

The helper knows two game builds by their code (the January 2025 Steam build and 1.005 on the Epic Games Store). On any
other it does not start, and the Lua scripts offer no stages.
